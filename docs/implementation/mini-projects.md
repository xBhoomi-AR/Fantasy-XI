# Mini Projects

Two smaller projects built up the RL/PPO skills the main system relies on.

**`mini_projects/rl_sandbox/`**
A DQN agent on a small, synthetic 10-gameweek FPL-like environment — learning RL/environment mechanics before real data.

**`mini_projects/PPO mini project/`**
PPO applied to portfolio management (not FPL) — learning PPO/Stable-Baselines3 itself before the real decision layer.

Both are exploratory, with their own `requirements.txt`, and separate from the production pipeline.
