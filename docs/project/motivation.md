# Problem & Motivation

Doing well in Fantasy Premier League means, every week, for 38 weeks straight:

- Picking a strong 15-player squad under a fixed budget.
- Deciding when a transfer is worth a points hit.
- Timing season-long chips correctly.
- Doing all of this from incomplete, noisy information about player performance.

## Why automate it?

FantasyXI splits the problem the way a real manager would:

1. **Predict** who's going to play well.
2. **Decide** how aggressively to act on that.
3. **Optimize** the best legal squad given that decision.

Each layer can be studied and improved independently — see [Architecture](architecture.md).
