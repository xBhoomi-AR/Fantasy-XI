# Understat Research

## Overview

Understat is an advanced football analytics platform that provides expected statistics (xG-based metrics) for players, teams, and matches. Unlike the Official Fantasy Premier League API, which primarily contains fantasy-oriented statistics, Understat focuses on underlying football performance. These advanced metrics help measure the quality of chances created, scoring opportunities, and overall player effectiveness.

For FantasyXI, Understat serves as a complementary data source by providing richer analytical features that improve player performance prediction.
